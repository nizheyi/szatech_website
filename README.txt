SZATech MkDocs website - clean version

This is the clean production source project. Analytics integration is intentionally not included yet.

Local preview:
1. Open Anaconda Prompt.
2. cd into this folder.
3. Run: mkdocs serve
4. Open: http://127.0.0.1:8000/

Chinese page:
http://127.0.0.1:8000/zh/

Main files:
- mkdocs.yml: site configuration
- docs/index.md: English homepage
- docs/zh/index.md: Chinese homepage
- docs/assets/stylesheets/extra.css: site styling
- docs/assets/javascripts/site.js: inquiry email and copy-email behavior
